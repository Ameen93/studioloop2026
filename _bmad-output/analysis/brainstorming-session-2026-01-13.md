# Brainstorming Session Results

**Facilitator:** Ameen
**Date:** 2026-01-13

## Session Overview

**Topic:** MVP Scope & Feature Prioritization for Gym Management + Class Marketplace Platform

**Goals:**
1. Define the minimum feature set for both apps to launch together
2. Identify must-have vs nice-to-have features for each user type (gyms, consumers)
3. Surface risks and unknowns to address early
4. Explore differentiation opportunities against future competitors

### Context Summary

**Project Components:**
- FastAPI Backend (shared API layer)
- Gym Management App (B2B - for gym owners/staff)
- Class Marketplace App (B2C - for consumers)

**Target Market:** Cape Town, South Africa (underserved by ClassPass-like solutions)

**Value Propositions:**
- Gyms: Affordable management software (existing solutions too expensive for smaller gyms)
- Consumers: Discounted off-peak classes + unified membership management across gyms

**Revenue Model:**
- Low monthly SaaS fee from gyms
- Commission on class bookings
- Commission on membership management
- Consumer subscription (X classes/month across network)

**Constraints:**
- Solo founder
- Both apps launching together
- Some gym leads already in place

### Session Approach

**Selected:** Progressive Technique Flow
- Start broad to capture all possibilities
- Systematically narrow to actionable priorities
- Flow: Diverge → Cluster → Evaluate → Converge
