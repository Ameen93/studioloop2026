# Story 0.6: Configure Hey API for Client Generation

Status: review

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a **developer**,
I want the API client auto-generated from OpenAPI schema with TanStack Query hooks,
so that frontend apps have type-safe API access.

## Acceptance Criteria

1. **Given** the backend exposes an OpenAPI schema at `/api/v1/openapi.json` **When** I run the Hey API generation script **Then** `packages/api-client/src/generated/` contains TypeScript types for all schemas
2. `packages/api-client/src/generated/` contains service functions for all endpoints
3. `packages/api-client/src/hooks/` contains TanStack Query hooks wrappers
4. All apps can import and use `@sl/api-client` package
5. API calls use snake_case field names per ARCH-25
6. Regeneration can be triggered via `pnpm generate:api`

### Technical Decisions

1. **Hey API over other generators**: Official OpenAPI-TypeScript generator with first-class TanStack Query support
2. **@hey-api/client-fetch**: Lightweight fetch-based client (no axios dependency)
3. **Generated code in src/generated/**: Separate from handwritten code, easy to regenerate
4. **Hooks in src/hooks/**: TanStack Query hooks for data fetching

### Hey API Configuration

```typescript
// openapi-ts.config.ts
import { defineConfig } from '@hey-api/openapi-ts';

export default defineConfig({
  client: '@hey-api/client-fetch',
  input: 'http://localhost:8000/api/v1/openapi.json',
  output: {
    path: 'src/generated',
    format: 'prettier',
  },
  plugins: [
    '@hey-api/typescript',
    '@hey-api/sdk',
    {
      name: '@hey-api/tanstack-react-query',
      output: 'src/hooks',
    },
  ],
});
```

### Snake_case Verification

Generated types should have snake_case field names matching the API:
```typescript
// Expected generated type
interface UserPublic {
  id: string;
  email: string;
  full_name: string | null;  // snake_case, not fullName
  is_active: boolean;
  is_superuser: boolean;
  created_at: string;        // snake_case, not createdAt
}
```
